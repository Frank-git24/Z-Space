# Z-Space: Digitação Espacial

Jogo espacial do gênero Shoot 'em up / Typing Game, desenvolvido em Python com Pygame.

## Como jogar

### Windows (sem Python)
1. Baixe o arquivo Z-Space.exe.
2. Execute o arquivo.

### Executar pelo código-fonte
1. Instale o Python.
2. Instale as dependências:

   pip install -r requirements.txt

3. Execute:

   python main.py

## Tecnologias
- Python
- Pygame

## Estrutura
- main.py: código-fonte.
- assets/: imagens e sons.
- highscores.json: recordes.
- Z-Space.exe: versão executável.

## Objetivo
Desenvolver habilidades de digitação enquanto enfrenta inimigos em um ambiente espacial.
